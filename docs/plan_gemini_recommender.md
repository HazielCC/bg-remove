# Plan: Dynamic Training Config using Gemini API

## Objective
Replace the heuristic-based config recommendation in `backend/routers/training.py` with an intelligent, dynamic recommendation generated by the Gemini API.

## Scope
Modify `backend/routers/training.py`.

## Tasks
1. Import `google.genai` and `google.genai.types` in `backend/routers/training.py`.
2. Create an async function `_ask_gemini_for_config(stats: dict, stage: str, has_pretrained: bool)` that formats the dataset stats into a prompt.
3. Use Gemini Structured Outputs (Pydantic schema `ConfigOutput`) to force the API to return a precise JSON containing the recommended parameters (`epochs`, `lr`, `batch_size`, `img_size`, `train_split`, `val_split`, etc.) and a list of `reasons`.
4. Update `recommend_training_config` endpoint to await this new function. If Gemini is unavailable or fails, fallback to the existing heuristics.
5. Return the parsed recommendation to the frontend.

## Verification
Compile backend files and ensure `pydantic` types match what the frontend expects.
